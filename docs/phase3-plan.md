## 一、三期待实现功能

### F10. 网球圈社区（高优先级）

**背景**：`pages/tennis-circle/index` 是 tabBar 三个主入口之一，但当前完全是空壳页面（WXML 仅显示"即将上线"）。这是用户活跃度和留存的核心模块。

**实现内容**：

**F10.1 数据模型扩展**

新增 `posts` 集合：

| 字段 | 类型 | 说明 |
|------|------|------|
| `_id` | string | 自动生成 |
| `author_id` | string | 发布者 OPENID |
| `content` | string | 文字内容（max 5000） |
| `images` | array\<string\> | 图片（云存储 fileID） |
| `video` | string | 视频（可选，云存储 fileID） |
| `topic` | string | 话题标签（约球/技术/装备/赛事/其他） |
| `location` | object | 可选位置信息 `{ lat: number, lng: number, name: string, address: string }` |
| `tags` | array\<string\> | 自定义标签 |
| `like_count` | number | 点赞数 |
| `comment_count` | number | 评论数 |
| `view_count` | number | 浏览数 |
| `is_pinned` | boolean | 是否置顶 |
| `status` | string | active/hidden/reported |
| `created_at` | Date | |
| `updated_at` | Date | |

新增 `comments` 集合：

| 字段 | 类型 | 说明 |
|------|------|------|
| `_id` | string | |
| `post_id` | string | 所属帖子 |
| `author_id` | string | 评论者 OPENID |
| `content` | string | 评论内容 |
| `reply_to` | string | 回复的评论ID（可选） |
| `status` | string | visible/hidden |
| `created_at` | Date | |

新增 `likes` 集合：

| 字段 | 类型 | 说明 |
|------|------|------|
| `_id` | string | |
| `target_type` | string | post/comment |
| `target_id` | string | |
| `user_id` | string | 点赞者 OPENID |
| `created_at` | Date | |

**F10.2 云函数**

创建 `cloudfunctions/social/` 云函数：

| Action | 功能 |
|--------|------|
| `post/list` | 帖子列表（分页、按话题筛选、置顶优先、最新/最热排序），关联用户信息 |
| `post/detail` | 帖子详情 + 前N条评论 |
| `post/create` | 发帖（校验内容/图片数量） |
| `post/delete` | 删帖（仅作者或管理员） |
| `post/like` | 点赞/取消点赞（toggle），更新 `like_count` |
| `comment/create` | 评论/回复评论 |
| `comment/list` | 获取帖子的分页评论列表 |

**F10.3 前端页面**

| 页面 | 功能 |
|------|------|
| `pages/tennis-circle/index`（现状是 tabBar 空壳） | 帖子列表瀑布流、话题筛选栏（约球/技术/装备/赛事/全部）、发布按钮（悬浮）、下拉刷新、触底加载更多 |
| `pages/social/post-detail/index`（新建） | 帖子全文 + 图片轮播 + 视频播放 + 评论列表（分页） + 评论输入框 + 点赞 |
| `pages/social/post-create/index`（新建） | 富文本编辑（文字+表情）、图片上传（最多9张）、话题标签选择、位置选择 |

### F11. 活动报名与参与（高优先级）

**背景**：一期实现了活动的创建和列表查看，但缺少"报名/参加"的闭环。活动创建后用户无法正式加入。

**实现内容**：

**F11.1 云函数**

新增 `cloudfunctions/activity/actions/` 下的 action：

| Action | 功能 |
|--------|------|
| `join` | 用户报名参加活动。校验 `current_count < max_participants`，原子增加 `current_count`，添加参与者记录。满员时自动将 `status` 更新为 `full` |
| `leave` | 退出活动。减少 `current_count`，移除参与者记录。如之前为 `full` 则恢复为 `open` |
| `cancel` | 发起者取消活动。设置 `status='cancelled'`，通知所有已报名用户 |
| `getParticipants` | 获取活动参与者列表（含用户信息：头像/昵称/等级） |

**F11.2 前端**
- 活动详情页增加"报名"按钮（显示剩余名额，满员时显示"已满"）
- 参与者列表展示
- "我的活动"tab（`pages/activity/list` 的第三个 tab）接入真实数据
- 活动创建者可以看到管理按钮（编辑/取消活动）

### F12. 模板消息推送（中优先级）

**背景**：当前通知仅存储在云数据库中，用户需主动打开小程序查看。模板消息可实现主动触达。

**实现内容**：
- 微信小程序后台申请模板消息（订单支付成功/活动提醒/审核结果/新评论/活动开始提醒等场景）
- 云函数中集成模板消息发送（`cloud.openapi.subscribeMessage.send`）
- 前端在关键操作前请求订阅授权
- 场景覆盖：
  | 场景 | 触发时机 |
  |------|---------|
  | 订单支付成功 | `order/pay` 完成后 |
  | 教练审核结果 | `coach/approve` / `coach/reject` 完成后 |
  | 活动开始提醒 | 活动开始前1小时/1天 |
  | 评价回复通知 | `review/reply` 完成后 |
  | 活动被取消 | `activity/cancel` 完成后 |

---

### F13. 数据看板（低优先级）

**背景**：管理员需要了解平台运营状况。

**实现内容**：

**F13.1 云函数**

新增 `cloudfunctions/admin/` 云函数：

| Action | 功能 |
|--------|------|
| `dashboard` | 核心指标：注册用户数、活跃教练数、订单数/GMV、评价数、活动数 |
| `trends` | 趋势数据：按天/周/月的订单量、用户增长、教练申请量 |
| `hotspots` | 热门数据：最受欢迎教练TOP10、最活跃城市、热门时段 |

**F13.2 前端**
- 新建"管理后台"页面（仅管理员可见入口）
- 仪表盘卡片展示核心指标
- 简单折线图展示趋势（使用 echarts-for-weixin 或 canvas 自绘）

## 三、三期完成后的状态

三期交付后，TennisVibe 从**工具型小程序**进化为**网球社交平台**：

```
首页 → 约球匹配 → 加入/创建活动 → 活动签到/互动
     → 网球圈社区 → 发帖分享 → 点赞评论
     → 约教练（完整付费流程）
     → 收到模板消息推送 → 提升回访率
管理员 → 数据看板 → 了解运营状况
```

至此，项目的"约球 + 约教练 + 社区"三大核心场景全部落地，形成完整的**网球生态闭环**。
